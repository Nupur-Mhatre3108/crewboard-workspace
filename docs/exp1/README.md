# Experiment 1 — Frontend Foundation & UI Architecture

## Objective
Establish a clean, aesthetic, and responsive collaborative Kanban workspace UI using React 18, Vite, Tailwind CSS, and Lucide React.

## Key Deliverables
- [x] Pastel & Cucumber Design System (`#F5FBF6`, `#35654D`, Sage, Butter, Peach, Lavender, Powder Blue)
- [x] 9 Reusable Core Components (`Navbar`, `Sidebar`, `Button`, `Input`, `StatsCard`, `ProjectCard`, `TaskCard`, `KanbanColumn`, `Modal`)
- [x] 5 Connected Routes (`/`, `/login`, `/register`, `/dashboard`, `/board`)
- [x] Clean Mock Dataset for CrewBoard Semester Project (`mockData.js`)
- [x] Future Experiment Architecture Ready
